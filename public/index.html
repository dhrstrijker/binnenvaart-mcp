binnenvaart-mcp

An open MCP server that brings official EuRIS inland-shipping data into any LLM chat tool.

Model Context Protocol endpoint (Streamable HTTP):

POST /api/mcp

Add it to an MCP client (Cursor, Claude, …) as a remote server pointing at /api/mcp on this domain. Open data — no key required.

Data source: EuRIS (eurisportal.eu).
